🔗 드라이브 연결

Apps Script 웹 앱 주소를 넣으면 드라이브 사진을 불러옵니다.

주소는 이 브라우저에만 저장됩니다. 사진은 진홍님 드라이브의 「진홍 포토 갤러리」 폴더(하위 앨범 포함)에서만 불러옵니다.
처음 한 번만 — 설치 방법
  1. 진홍님 구글 계정으로 script.google.com → 새 프로젝트
  2. 받은 photo-apps-script.txt 내용을 그대로 붙여넣고 저장
  3. [배포] → [새 배포] → 웹 앱 · 실행: 나 · 액세스: 모든 사용자
  4. 나온 /exec 주소를 위 칸에 붙여넣고 [저장]
사진을 더하거나 지우려면 관리자 PIN이 필요합니다. 드라이브 폴더에서 직접 올려도 됩니다.
