# 📷 진홍's 포토 갤러리

구글 드라이브의 **「진홍 포토 갤러리」 폴더**(그 안의 하위 앨범 폴더 포함)에 담긴 사진을 모아 보는
개인 포토 홈페이지입니다. GitHub Pages 로 열리는 정적 페이지 한 장(`index.html`)이고,
사진은 **본인 구글 계정의 Apps Script 웹 앱**을 통해 읽습니다.
드라이브 폴더는 비공개 그대로 두고, 외부에 사진을 공유하지 않습니다.

- 주소: https://hong3256.github.io/Hong-photo/
- 앨범(하위 폴더) 탭 · 검색 · 최신순/오래된순 · 전체화면 라이트박스(밀어서 넘기기·키보드·원본 다운로드)
- 관리자 PIN(스크립트의 `ADMIN_PIN`)으로 **웹에서 바로 사진 올리기·지우기**(드라이브 휴지통)
- 휴대폰 홈 화면에 설치(PWA), 오프라인에서도 화면은 열림

## 처음 한 번만 — 연결하기

1. https://script.google.com → **새 프로젝트** (이름 예: `진홍 포토 갤러리 API`)
2. 편집기의 기본 코드를 지우고, 진홍님이 받은 **`photo-apps-script.txt`** 내용을 그대로 붙여넣고 저장
   *(이 저장소에는 폴더 ID·웹 앱 주소·사진이 들어 있지 않습니다. 스크립트는 따로 보관합니다.)*
3. **[배포] → [새 배포] → 웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - [배포] → 액세스 승인 → 계정 선택 → 고급 → 이동 → 허용
4. 나온 `https://script.google.com/macros/s/…/exec` 주소를
   갤러리 오른쪽 위 **[🔗 연결]** 에 붙여넣고 **[연결 확인] → [저장]**

> 주소와 제목은 그 브라우저(localStorage)에만, 열람 토큰과 관리자 상태는 탭을 닫으면 사라지는
> sessionStorage 에만 저장됩니다. 저장소에는 어떤 개인 정보도 들어 있지 않습니다.

## 사진 넣기

| 위치 | 화면 |
| --- | --- |
| 「진홍 포토 갤러리」 바로 아래 | ‘전체’에만 표시 (앨범 없음) |
| 「진홍 포토 갤러리」 안의 하위 폴더 | 그 폴더 이름이 **앨범 탭**으로 표시 |

- 드라이브 앱/웹에서 폴더에 사진을 올려도 되고, 갤러리에서 **[＋ 사진 올리기]**(관리자)로 올려도 됩니다.
- 웹 업로드는 기본으로 긴 변 2000px·JPEG 품질 86%로 줄여서 올립니다(원하면 끌 수 있음).
- 삭제는 **드라이브 휴지통으로 이동**이며 30일 안에 되살릴 수 있습니다.
- 관리자 PIN 은 Apps Script 상단의 `ADMIN_PIN` 값입니다(기본값 그대로면 4자리).

## 잠그고 싶을 때 (선택)

`photo-apps-script.txt` 맨 위 한 줄만 바꾸고 다시 배포하면 됩니다.

```js
var VIEW_PIN = '';      // 지금: 누구나 열람 (공개 앨범)
var VIEW_PIN = '비밀번호';  // 이렇게 바꾸면 열람에도 비밀번호 필요
```

관리자(올리기·삭제) PIN 은 같은 파일의 `ADMIN_PIN` 에서 바꿉니다.

## 안전장치

- 서버(Apps Script)는 `FOLDER_ID` 폴더와 그 **한 단계 하위 폴더**의 이미지 파일만 읽습니다.
  다른 드라이브 파일은 목록에 나오지 않고, 파일 ID를 알아도 열람/삭제 요청이 거부됩니다.
- 이미지도 `data:` 로 내려오므로 드라이브 파일을 ‘링크 공유’로 공개할 필요가 없습니다.
- 저장소(공개)에는 폴더 ID·사진·웹 앱 주소가 들어가지 않습니다. 연결은 방문한 브라우저에서 합니다.

## 파일

```
index.html               화면 전체(스타일·스크립트 포함, 의존성 없음)
manifest.json, sw.js     PWA 설치·오프라인
icon-*.png, favicon.ico  아이콘 (tools/make_icons.py 로 생성)
tools/test_apps_script.py Apps Script 로직 단위 테스트(가짜 드라이브)
tools/test_gallery.py     화면 동작 테스트(Playwright, 가짜 API)
```

## 개발/확인

```bash
python3 -m http.server 8080          # http://localhost:8080
python3 tools/test_apps_script.py    # ping/list/img/upload/delete/PIN
python3 tools/test_gallery.py        # 빈 화면·그리드·라이트박스·관리자·잠금
```

## 한계

- Apps Script 응답은 큰 사진일수록 느립니다(썸네일 640px, 원본은 12MB 까지 그대로/그 이상은 축소본).
- 구글 드라이브의 사진 촬영일(EXIF)은 Apps Script 에서 읽지 않고 **파일 수정일** 기준으로 정렬합니다.
- 사진은 갤러리에 `data:` 로 내려오므로, 아주 큰 사진을 많이 열면 모바일 데이터를 씁니다(썸네일 640px).
